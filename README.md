🎥 RealMeet – Video Calling Web Application







🚀 Live Demo

👉 https://real-meet-frontend.onrender.com/

✨ Features
🔴 Real-time video & audio communication
👥 Room-based video calling (join via unique room ID)
💬 Live chat during video calls
🔗 Peer-to-peer connection using WebRTC
⚡ Low-latency communication
🔌 Signaling server using Socket.io
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript (React if used)
Backend: Node.js, Express.js
Real-Time Communication: WebRTC
Signaling: Socket.io
⚙️ How It Works
WebRTC enables peer-to-peer video/audio streaming
Socket.io handles signaling (SDP & ICE candidate exchange)
Users join rooms and connect directly with peers
📦 Installation & Setup
# Clone the repository
git clone https://github.com/sumitprasad9411/realmeet.git

# Navigate to project folder
cd realmeet

# Install dependencies
npm install

# Start the server
npm start
